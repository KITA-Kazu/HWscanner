GitHub Pages での無料公開手順 (3ステップ)

このアプリは外部サーバー不要（完全ブラウザ完結）のため、GitHub Pagesに置くだけで家族全員のスマホやiPadから無料でアクセス可能になります。

1 GitHubでリポジトリを作成

GitHubにログインし、「New repository」から新しいリポジトリ（例: homework-eraser）をPublicで作成します。

2 このコードを index.html としてアップロード

右上の「Add file」→「Upload files」を選択し、このHTMLファイルをファイル名 index.html のままドラッグ＆ドロップしてCommitします。

3 Pages を有効化

リポジトリの「Settings」タブ → 左メニューの「Pages」を開き、Build and deployment の Branch を main（またはmaster）/ / (root) にして「Save」を押します。約1分後に専用のURLが発行されます！

スマホアプリとして使う方法
iPhone / iPad (Safari)

画面下の共有ボタン（四角から矢印が出たアイコン）をタップし、メニューから「ホーム画面に追加」を選びます。

Android (Chrome)

右上のメニュー（︙）をタップし、「アプリをインストール」または「ホーム画面に追加」を選びます。
